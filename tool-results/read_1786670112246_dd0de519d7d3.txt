    37→## Implementation Strategy
    38→Use a **CSS-based viewport swap** (no JS hydration risk):
    39→- `src/app/page.tsx` renders `Hero3DSlider` (shared) then:
    40→  - `<div className="hidden md:block">` → all existing desktop sections
    41→  - `<div className="md:hidden">` → all new mobile sections
    42→  then `Footer` (shared).
    43→- New mobile sections live in `src/components/sections/mobile/`.
    44→- Each mobile section imports the **same data** from `@/data/landing` as its desktop
    45→  counterpart (same content) but renders a **different layout/design**.

    47→## Mobile Design Language — "Immersive App" (cohesive across all mobile sections)
    48→This is deliberately different from the desktop's centered, card-grid, subtle-shadow look.
    49→
    50→**Principles**
    51→1. **Bold alternating backgrounds** — alternate navy-gradient sections
    52→   (`bg-gradient-to-b from-[#16305B] to-[#0E1F3F]`, white text) with warm cream/white
    53→   sections. Dramatic contrast, app-like.
    54→2. **Left/right-aligned editorial headings** (NOT centered). In RTL the heading block sits
    55→   at the start (right). Use a small orange **vertical accent bar** + an optional numbered
    56→   chip (`۰۱` … `۰۱۱` in Persian digits) for an editorial feel. Punchier, smaller titles.
    57→3. **Horizontal snap ribbons** (`snap-x snap-mandatory`) replace desktop grids/pinned rails.
    58→   Cards snap into view one at a time (`snap-center`, `w-[78%]`).
    59→4. **Glassmorphism on navy** (`bg-white/10 backdrop-blur-md border border-white/15`,
    60→   white text). On light sections: solid `rounded-3xl` white cards with a coloured
    61→   top accent stripe and soft shadow.
    62→5. **Bigger touch targets** — min 44px, generous padding. Big full-width CTA buttons
    63→   (orange gradient `from-orange-500 to-orange-600`).
    64→6. **Persian digits** where numbers are shown (use a small helper).
    65→7. **Sticky in-section sub-tabs** where a section has tabs (pill chips, horizontally
    66→   scrollable, `ar-no-scrollbar`).
    67→8. Use `framer-motion` for subtle entrance animations (fade/slide up) — already a dep.
    68→9. Keep using `Icon`, `ImageSlot`, and existing shadcn primitives. Do NOT reinvent icons.
    69→
    70→**Shared kit** — `src/components/sections/mobile/_kit.tsx` exports:
    71→- `MNAV` (= `#16305B`), `MORANGE` (= `#F26A21`), `toFa(num)` Persian-digit helper.
    72→- `<MobileSectionShell>` — wrapper: `<section className="py-12 ...">` with a
    73→  `px-4` container and a `data-mobile-section` attr.
    74→- `<MobileHeading>` — props `{ index, title, desc?, onDark? }` → renders the numbered
    75→  chip + orange accent bar + bold title + optional desc. `onDark` switches text to white.
    76→- `<SnapRail>` — horizontal snap scroller (`flex gap-4 overflow-x-auto snap-x snap-mandatory
    77→  ar-no-scrollbar -mx-4 px-4`).
    78→- `<GlassCard>` / `<SolidCard>` — reusable card primitives.
    79→- `<GradientCTA>` — full-width orange gradient button.
